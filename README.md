# 🍽 Calorie Bot — Telegram-бот для розрахунку калорій по фото

Надсилаєш фото страви — бот визначає продукти, оцінює вагу порцій і рахує
калорії та БЖВ (білки / жири / вуглеводи). Розпізнавання робить Claude API
(модель `claude-opus-5`, vision + structured outputs).

## Можливості

- 📸 Аналіз фото їжі: кожна позиція окремо + загальна сума
- ✍️ Уточнення через підпис до фото («гречка 200 г, курка 150 г»)
- 📊 Оцінка впевненості та коротка порада
- 🤔 Коректна відповідь, якщо на фото немає їжі

## Запуск

1. Створи бота через [@BotFather](https://t.me/BotFather) і отримай токен.
2. Отримай API-ключ Anthropic на https://platform.claude.com/.
3. Встанови залежності (Python 3.10+):

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

4. Скопіюй `.env.example` у `.env` і впиши токени:

   ```bash
   cp .env.example .env
   ```

5. Запусти:

   ```bash
   python -m bot.main
   ```

## Структура

```
bot/
  analyzer.py  # запит до Claude, схема відповіді, форматування
  main.py      # Telegram-хендлери та запуск
```

## Примітки

- Калорії — це **приблизна** оцінка за фото, а не лабораторний аналіз.
- Увімкнено серверний fallback (`fallbacks: "default"`): якщо модель
  відмовить у запиті, API автоматично перезапустить його на іншій моделі.
- Модель і рівень `effort` можна змінити в `bot/analyzer.py`.
