# 🍽 Calorie Bot — ШІ-дієтолог у Telegram

Надсилаєш фото їжі — бот розпізнає страви, оцінює вагу порцій, рахує калорії та БЖВ,
веде щоденник, малює графіки й підбадьорює досягненнями.

**Повністю безкоштовно:** ШІ — безкоштовний тариф Google Gemini, Telegram-бот — безкоштовний,
запускати можна на своєму ПК або безкоштовному сервері. За бажання можна перемкнутися на
платний Claude (`AI_PROVIDER=claude`).

## Функції

| | |
|---|---|
| 📸 **Аналіз фото** | Страви, вага порцій, калорії, БЖВ, оцінка корисності 1–10, цікавий факт |
| ✍️ **Аналіз тексту** | «2 яйця, тост з авокадо і капучино» — теж порахує |
| ⚖️ **Розмір порції** | Кнопки ½ / ×1 / ×1.5 / ×2 перед записом |
| 💪 **«Скільки це бігу?»** | Хвилини ходьби, бігу та велосипеда, щоб спалити страву |
| 👤 **Профіль і норма** | Формула Міффліна–Сан Жеора: норма ккал, БЖВ і води під ціль |
| 📊 **/today** | Підсумок дня з прогрес-барами і списком прийомів їжі |
| 📈 **/week** | Графік калорій за тиждень, середнє, баланс, дні в нормі |
| 💧 **/water** | Трекер води в один дотик |
| ⚖️ **/weight** | Облік ваги з графіком; норма перераховується автоматично |
| 🍳 **/suggest** | ШІ підбирає, що зʼїсти, щоб вписатися в залишок калорій |
| 💬 **/ask** | Питання ШІ-дієтологу з урахуванням твого дня |
| 🏆 **Досягнення** | 12 бейджів: серії днів, норма води, «Снайпер», «Здорова тарілка»… |
| 🔥 **Серії** | Скільки днів поспіль ти ведеш щоденник |
| 🔔 **Нагадування** | Удень — якщо ще нічого не записано, увечері — підсумок дня |
| 📒 **/export** | Весь щоденник у CSV (відкривається в Excel / Google Таблицях) |
| ↩️ **/undo** | Видалити останній запис |
| 🔒 **Приватний доступ** | Лише ти і ті, кого запросиш: `/invite` (посилання), підтвердження кнопкою, `/users` |
| 🛡 **Захист лімітів** | Чужі люди отримують «🔒 Приватний бот»; денний ліміт запитів до ШІ на людину |

## Швидкий старт

```bash
python -m venv .venv && source .venv/bin/activate   # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env        # впиши TELEGRAM_BOT_TOKEN, GEMINI_API_KEY, OWNER_ID
python -m bot.main
```

Детальна інструкція — створення бота, отримання ключів, розміщення на сервері й
безкоштовні варіанти — у **[DEPLOY.md](DEPLOY.md)**.

## Структура

```
bot/
  main.py       # запуск, реєстрація команд
  handlers.py   # фото/текст, статистика, вода, вага, коуч, нагадування
  profile.py    # анкета профілю
  access.py     # власник, запрошення, підтвердження доступу
  analyzer.py   # запити до ШІ (Gemini або Claude)
  nutrition.py  # норми, прогрес-бари, досягнення
  common.py     # меню, доступ, ліміти, підсумок дня
  charts.py     # графіки
  db.py         # SQLite
  config.py     # налаштування з .env
```

⚠️ Оцінка калорій за фото приблизна і не є медичною порадою.
